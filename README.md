## 📖 About dotfiles

**_dotfiles_** is the source of truth for a personal _Ubuntu_ workstation, capturing the user environment, system tweaks, and application preferences in a modular, idempotent configuration that can be reapplied to any fresh _Ubuntu LTS_ install.

## 📚 Documentation

For detailed information on **_dotfiles_** installation and usage instructions, please refer to the project's [Wiki](https://github.com/samariafar/dotfiles/wiki). The Wiki provides comprehensive guides and resources to help you get started with **_dotfiles_** and make the most out of its features. Additionally, you can find answers to the most frequently asked questions (FAQs) in the Wiki.
